Arise Register

A church registration and usher-management system built with Flutter and Firebase to streamline member registration and event administration.

Flutter, Dart, Firebase, Cloud Firestore

OVERVIEW

Arise Register is a Flutter and Firebase-based church registration and usher-management system designed to make church event registration and participant management more organized. The system provides a digital alternative to manual registration processes and helps church administrators manage registration information through a centralized application. And it was made specifically for Arise and Shine Glory ministries International

THE PROBLEM

Manual attendance recording during church services can make it difficult to maintain organized records, track service attendance accurately, and produce reports for different branches and services.

THE SOLUTION

Arise Register provides a digital workflow for managing church services and recording attendees. Users are assigned roles and branches, allowing the system to keep registration activities associated with the appropriate branch and service. Chief Ushers can set up services and monitor registrations, while ushers can focus on attendee registration during active services.

FEATURES

→ Branch-based user access

→ Role-based access

→ Service setup and management

→ Attendee registration

→ Real-time registration counting

→ Attendance history

→ Service-specific registration records

→ Usher registration auditing

→ PDF attendance reports

→ Regular and special service types

→ Branch-specific data management

DEVELOPMENT

The application was developed with Flutter and Dart and uses Firebase Authentication and Cloud Firestore for user access and data management. Service records are associated with branches, while attendee registrations are associated with individual services. Firestore real-time streams are used for live registration counts, and atomic increments are used when updating service registration totals. The application also generates PDF attendance reports for selected services.stem.

RESULT

A digital attendance management system that gives church ushering teams a structured way to start services, register attendees, monitor attendance, review historical registration records, and generate service attendance reports.
